♻️ પાણી બચાવવાની યાદી

  • વાસણ ધોતાં નળ સતત ચાલુ ન રાખો.
  • ટૂંકું સ્નાન કરો અને લીકેજ તપાસો.
  • છોડને સવારે અથવા સાંજે જરૂર મુજબ પાણી આપો.
  • યોગ્ય રીતે એકત્ર કરેલું ગ્રે-વોટર બાગાયત જેવા બિન-પીવાના ઉપયોગ માટે જ વાપરો.
  • ગ્રે-વોટર પીવા કે રસોઈ માટે વાપરવું નહીં.

📲 એપ તરીકે ઇન્સ્ટોલ કરો

આ PWA ફાઇલ છે. તેને ખરેખર હોમ સ્ક્રીન પર એપ તરીકે ઇન્સ્ટોલ કરવા માટે આ ફાઇલો HTTPS વેબસાઇટ પર હોવી જરૂરી છે. માત્ર ફોનમાં HTML ફાઇલ ખોલવાથી દરેક બ્રાઉઝરમાં Install વિકલ્પ નહીં દેખાય.

AI અંગે સ્પષ્ટતા: આ આવૃત્તિમાં નિયમ આધારિત સ્માર્ટ વિશ્લેષણ છે—ઑનલાઇન ChatGPT અથવા તાલીમ લીધેલું મશીન-લર્નિંગ મોડલ નથી. Arduino કે સેન્સરની જરૂર નથી.
